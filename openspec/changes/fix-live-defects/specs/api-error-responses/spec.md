# Spec Delta

## Purpose

约定接口在拒绝请求时的响应：业务拒绝保留它的状态码和提示，不被通用的异常兜底改成 500；任何错误响应都不暴露内部异常。

## ADDED Requirements

### Requirement: 业务拒绝不被兜底改写

接口在处理中主动拒绝请求时，客户端 SHALL 收到这次拒绝原本的状态码和提示文案；通用的异常兜底 SHALL 只处理未预料的异常。

#### Scenario: 截止时间早于当前时间

- **WHEN** 用户创建预言时给出的截止时间早于当前时间
- **THEN** 收到 400"截止时间必须晚于当前时间"，而不是 500

#### Scenario: 流量榜日期格式错误

- **WHEN** 请求流量榜时日期格式错误
- **THEN** 收到 400 和原来的日期格式提示

### Requirement: 错误响应不暴露内部异常

错误响应 SHALL NOT 包含异常原文、堆栈或服务器文件路径；这些信息 SHALL 只写入应用日志。

#### Scenario: 自建线路操作出现内部错误

- **WHEN** 自建线路的某个操作出现未预料的异常
- **THEN** 响应只包含通用的失败提示，异常详情写入日志
