# media-access Specification

## Purpose
约定媒体账号付费下载解锁的权限校验、积分扣除和永久标记事务边界，确保未绑定账号或重复解锁时不会错误扣除积分。

## Requirements

### Requirement: 付费下载解锁

用户付费解锁某项服务的下载权限时，扣分和设置永久解锁标志 SHALL 在同一个事务里完成，并在锁定用户的媒体账号后复查标志。

- 用户在该服务上没有绑定账号时，SHALL 返回失败"请先绑定 Plex/Emby 账户"，不扣分，不通知管理员。
- 已经解锁时，SHALL 返回原来的"无需重复解锁"，不扣分。
- 媒体服务器同步失败时，与现在一样只记录警告，解锁仍然有效。

#### Scenario: 未绑定时解锁

- **WHEN** 一个没有绑定 Emby 账号的用户直接请求解锁 Emby 下载
- **THEN** 收到"请先绑定 Plex/Emby 账户"，积分不变

#### Scenario: 双击解锁

- **WHEN** 用户连续发出两个解锁请求
- **THEN** 只扣一次分，第二个请求收到"无需重复解锁"
